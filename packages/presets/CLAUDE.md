# @vibeglobe/presets

Ready map types built only from free sources whose terms allow commercial use and redistribution: `europeOpen` (ADR 0182) gives Europe's Google Earth-like base maps (Satellite, Hybrid, Map, Relief) and overlays (labels and borders, roads, 3D buildings, 3D terrain), each source with its coverage, levels, licence, exact attribution and the day its terms were read.

## Rules

- A source is included only after its provider's own terms were read: a row in ADR 0182 and a record in `src/sources.ts` with the reading date. Terms that cannot be read keep it out, listed in `EXCLUDED_SOURCES` and `docs/open-questions.md`.
- Online sources cover land only (`EUROPE_LAND`, generated by `scripts/europe-land.ts` from Natural Earth; do not edit it by hand); the sea comes from the application's package.
- No DOM at import time; drives the engine only through public APIs (sources, `ImageryLayerOptions`, MapLibre style JSON, the offline engine's `source(…, { tiers })`).

## Commands

- `npx vitest run packages/presets` runs this package's tests.
- `npm run build` (root) builds it with `tsc -b` to `dist/` (ESM + declarations).

See the root `CLAUDE.md` for the workflow and `docs/guides/europe-preset.md` for its use.
