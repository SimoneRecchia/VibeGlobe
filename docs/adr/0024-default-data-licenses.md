# 0024. Licenses and attribution of the default datasets, re-verified

- Status: Accepted
- Date: 2026-10-21
- Milestone: M9

## Context

`PLAN.md` lists the default datasets with license notes "checked during planning: the agent must re-verify them before shipping". F332 asks for each dataset's current terms, with reading date and source link. For each, it asks whether commercial use and redistribution are free, and for the exact required attribution. The pipeline's configuration files must use that attribution text. The pipeline refuses sources whose terms forbid packaging (F333, ADR 0023).

The official pages were read on 2026-10-21. The build container cannot open some of them directly: `registry.opendata.aws`, `cloudless.eox.at`, `naturalearthdata.com`, `openstreetmap.org` and the OSMF operations site are blocked by its network policy. Their current text was then read through search-engine copies of the same pages and the licence documents they link to. Each row names the page that was read. The owner should open the links once from an unrestricted network before the first public release of data (`docs/open-questions.md`).

Notes:

- **Copernicus DEM:** the notice above is the "adapted or modified" form. Tiling and re-encoding are modifications. The licence also states that the organisations in charge of the Copernicus programme incur no liability for any use of the data; the hosting guide repeats this.
- **Sentinel-2 cloudless 2016:** EOX now names CC BY 4.0 for the 2016 edition (the 2017 announcement said CC BY-SA 4.0; the current, more permissive terms apply). The credit ends "2016 & 2017" because the southern-hemisphere data were acquired until March 2017. The requester-pays bucket `eox-s2maps` named in 2017 no longer exists (S3 answers `NoSuchBucket` on 2026-10-21). The source of the 2016 originals is an owner question; sample builds use the fixture stub (F340).
- **Natural Earth:** public domain, no permission needed; the credit is optional and is recorded so every output still names its source.
- **OpenStreetMap:** the extracts are ODbL. Tiles made from them are a Produced Work: the credit is required, and derived databases are share-alike. Public OSM tile servers are never used (F341, F344).

## Consequences

- Every pipeline output carries the exact text above in its metadata (F337). The data licenses document (`docs/data-licenses.md`, F345) lists the same rows and is checked against the metadata the pipeline emits.
- A change of terms means a new row (a new profile id when the old terms still apply to existing builds), a new reading date, and the test updated with it.
