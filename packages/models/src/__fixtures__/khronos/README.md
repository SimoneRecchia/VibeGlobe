# Khronos glTF sample models

Unmodified copies of a few models from the Khronos Group's [glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(branch `main`, fetched 2026-10-23), used by the conformance suite of `@vibeglobe/models` (F361). Each keeps its own
license; none is part of the published package.
