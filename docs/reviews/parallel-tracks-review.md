# Review of the parallel-track packages

One review (2026-10-22, review session on branch `claude/vigilant-ptolemy-11wj3l`) of every package merged from the
parallel tracks: `sources`, `offline`, `layers`, `vue`, `web-component`, `ui`, `gis` and `tools`. It reports only
correctness bugs and missing requirements against the packages' `feature_list.json` entries (ADR 0021, ADR 0022). Each
fix inside a package starts with a failing regression test; a finding that needs `core`, the renderer or the worker
goes to `docs/known-bugs.md` for the main session.

Status values: **fixed** (commit and regression test named), **deferred** (with the reason and where it is tracked).

| PT-02 | sources       | F233       | `archiveTransport` called its reader synchronously, so a malformed MBTiles database that throws in `statement.step()` made `start()` throw (the frozen contract says a transport never throws) and later still reported a timeout.                                                                                                                                    | fixed: a synchronous failure becomes a rejected read (no data); test "never throws when a reader fails synchronously" in `packages/sources/src/archive-transport.test.ts`                                    |
| PT-03 | sources       | F232, F257 | A connection dropped while the body was read (PMTiles ranges, Google tiles) raised a plain `TypeError`, which the transport reported as an empty `ok` tile: permanent no data instead of a retryable network error.                                                                                                                                                   | fixed: `readBody` raises `NetworkError`; test "reports a body cut off mid-read as a network error" in `packages/sources/src/archive-transport.test.ts`                                                       |
| PT-04 | sources       | F237       | KML altitude mode was read from any direct child of a placemark in document order, so a Google Earth `<LookAt>` with `gx:altitudeMode` before the geometry gave the feature the view's mode instead of the geometry's.                                                                                                                                                | fixed: only the placemark and its geometry elements are read; test "reads the altitude mode of the geometry, not of a LookAt before it (PT-04)" in `packages/sources/src/vector/formats.test.ts`             |
| PT-05 | sources       | F239       | A geometry-command error in a feature of type UNKNOWN (a MoveTo with several points) was fatal, so one such feature made the whole MVT tile no data, although the specification lets decoders ignore UNKNOWN geometry.                                                                                                                                                | fixed: such a feature is dropped and reported in `issues`; test "drops an UNKNOWN feature … (PT-05)" in `packages/sources/src/vector/mvt.test.ts`                                                            |
| PT-06 | sources       | F231, F227 | WMS requests sent the normalized code (`EPSG:3857`) even when the layers advertise only an alias such as `EPSG:900913`, which such servers refuse with an InvalidSRS exception: every tile blank.                                                                                                                                                                     | fixed: capabilities keep the advertised codes and requests send the one all layers share; test "sends the Web Mercator code the server advertises (PT-06)" in `packages/sources/src/ogc/wms-imagery.test.ts` |

## Packages without findings

- `gis`: CRS transforms (proj4js, ETRS89, UTM zones and the Norway and Svalbard exceptions), coordinate formats with
  carry-over rounding and decimal commas, parsing of every written format, geodesic measurement and view-state
  serialization checked against F404 and F405.
- `ui`: control layer (add, remove, replace, extend), themes, English and Italian strings (every key), pluggable
  translations, keyboard operation and focus ring, debug toggle checked against F418, F428–F433 and F435.
- `vue`: component, SSR placeholder and hydration, event forwarding, unmount cleanup and composables checked against
  F473 and F477–F480.
