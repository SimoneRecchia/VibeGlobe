# 0025. Licenses and attribution of the default datasets, re-verified

- Status: Accepted (amended by 0185)
- Date: 2026-10-21
- Milestone: M9

## Context

`PLAN.md` lists the default datasets with license notes "checked during planning: the agent must re-verify them before shipping". F332 asks for each dataset's current terms, with reading date and source link. For each, it asks whether commercial use and redistribution are free, and for the exact required attribution. The pipeline's configuration files must use that attribution text. The pipeline refuses sources whose terms forbid packaging (F333, ADR 0024).

The official pages were read on 2026-10-21. The build container cannot open some of them directly: `registry.opendata.aws`, `cloudless.eox.at`, `naturalearthdata.com`, `openstreetmap.org` and the OSMF operations site are blocked by its network policy. Their current text was then read through search-engine copies of the same pages and the licence documents they link to. Each row names the page that was read. The owner should open the links once from an unrestricted network before the first public release of data (`docs/open-questions.md`).

Notes:

- **Copernicus DEM:** the notice above is the "adapted or modified" form. Tiling and re-encoding are modifications. The licence also states that the organisations in charge of the Copernicus programme incur no liability for any use of the data; the hosting guide repeats this.
- **Sentinel-2 cloudless 2016:** EOX now names CC BY 4.0 for the 2016 edition (the 2017 announcement said CC BY-SA 4.0; the current, more permissive terms apply). The credit ends "2016 & 2017" because the southern-hemisphere data were acquired until March 2017. The requester-pays bucket `eox-s2maps` named in 2017 no longer exists (S3 answers `NoSuchBucket` on 2026-10-21). The source of the 2016 originals is an owner question; sample builds use the fixture stub (F340).
- **Natural Earth:** public domain, no permission needed; the credit is optional and is recorded so every output still names its source.
- **OpenStreetMap:** the extracts are ODbL. Tiles made from them are a Produced Work: the credit is required, and derived databases are share-alike. Public OSM tile servers are never used (F341, F344).

## Consequences

- Every pipeline output carries the exact text above in its metadata (F337). The data licenses document (`docs/data-licenses.md`, F345) lists the same rows and is checked against the metadata the pipeline emits.
- A change of terms means a new row (a new profile id when the old terms still apply to existing builds), a new reading date, and the test updated with it.

## Update 2026-10-22

The owner chose the ESA WorldCover 2021 Sentinel-2 composite as the detailed imagery source instead of Sentinel-2 cloudless 2016, whose originals are no longer downloadable (ADR 0026). Its row `esa-worldcover-s2-2021` was added to the table on 2026-10-22, after reading the project's licence section and the AWS Open Data registry entry. The shipped configurations no longer use `s2cloudless-2016`; its row stays because the profile remains for builds that have the 2016 originals.

## Amendment 2026-10-24: the owner's reading

The owner read the license pages from an unrestricted network on 2026-10-24 (open question 23) and confirmed every row: Natural Earth is in the public domain; the Copernicus DEM on AWS needs no account and is not requester-pays; OpenStreetMap is ODbL, credited as "© OpenStreetMap contributors" (or "OpenStreetMap") linked to the copyright page; Sentinel-2 cloudless 2016 is CC BY 4.0, and the 2018–2025 editions are CC BY-NC-SA. No setting changes.

## Amendment 2026-11-01: Sentinel-2 cloudless removed

The owner removed what no build uses: the pipeline no longer reads Sentinel-2 cloudless (`s2cloudless` sources and the
`s2cloudless-2016` profile, F340 superseded). Every edition named in a source URL is now refused under one profile,
`eox-s2cloudless`: the 2018 and later editions are CC BY-NC-SA 4.0, and EOX's site asks its commercial licence for
commercial use while the 2016 edition's page names CC BY 4.0 (read 2026-11-01). The notes above on the 2016 edition
stay as the record of its earlier reading.
