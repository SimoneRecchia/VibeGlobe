# Playground

Demo app that exercises every engine feature; also the bed for visual, scenario and performance tests.

## Rules

- URL parameters drive it in tests: `?backend=webgpu|webgl2`, `?depth=fragment` (forces WebGL2's fragment-written depth path, ADR 0005), `?lon=&lat=&zoom=&heading=&tilt=` (initial view), `?debug=1` (debug overlay), `?imagery=world|levels|border&session=` (Web Mercator tiles from the fixture tile server, M3; `&gpuBudgetMB=&ramBudgetMB=` set the cache budgets), `?assets=<path>/` (the worker program and base image from another base URL, F100) and `?scenario=` with `frame-loop` (benchmark frame loop), `two-globes` (two instances), `drag` (continuous drag for the `drag-*` benchmarks; `?level=` sets the coarsest surface level and so the tile count, `?gpuTiming=1` records GPU time per frame), `street-level-jitter` and `depth-range` (debug quads for F057 and F058, `src/scenarios.ts`). `?experiment=gpu-probes` runs ADR 0004 and 0005's GPU readback probes instead of a globe (`src/gpu-probes.ts`). `?experiment=offscreen&render=main|worker` is the F065 measurement mode (`src/render-experiment/`, `npm run bench:offscreen`): the engine on the main thread or in a worker with OffscreenCanvas, with input, frame and overlay instrumentation. `?quality=low|medium|high|ultra|auto` (`&qualityAdaptive=0`, `&governor={json}`), `?gpuLoad=N` (debug: N extra full-screen passes, F401), `?atmosphere=off|low|medium|high|ultra`, `?fog=0`, `?sun=<ISO time>` and `?haze=` load the quality page (`src/quality-demo.ts`, hooks in `window.vibeglobeQuality`). `?scenario=3dtiles-city` streams the fixture city through the 3D Tiles render extension (`&tiles3d=plain|draco|meshopt|ktx2`, `&tileset=`, `&sse=`, `&budgetMb=`, `&decoders=`, `&debug3dtiles`, `&tour=1`: an endless tour over the city for the `3dtiles-city` benchmark, `src/tiles3d-tour.ts`) and `?scenario=3dtiles-google` Google Photorealistic 3D Tiles over Rome (`&googleKey=` from the environment, never committed; `&googleRegion=eea|other`, `&googleBase=`, `&googleSessionMs=`), hooks in `window.vibeglobeTiles3d` (`src/tiles3d-demo.ts`, M13). `?vectorStyle=<name or URL>` draws a MapLibre style from the fixture vector tiles and `?scenario=mvt-*` sets a vector tile scenario's style and view, hooks in `window.vibeglobeVectorTiles` (`src/vector-tiles-demo.ts`). Later milestones add their own (`?network=…` in M8) and document them here.
- Tests and benchmarks read the page through `window.vibeglobePlayground` (`src/test-hooks.ts`), never through private state; its `mount()` creates and destroys extra instances for the leak suite.
- The page must load without console errors (`e2e/playground.spec.ts`).
- Workspace packages resolve to their TypeScript sources through the `source` export condition (`vite.config.ts`).

## Commands

- `npm run dev` (root) serves it at http://localhost:5173 (`PLAYGROUND_PORT` to change); `npm run preview -w @vibeglobe/playground` serves the production build at http://localhost:5176 (`PLAYGROUND_PREVIEW_PORT`), which the end-to-end tests of shipped bundles use.
- `npm run test:e2e` (root) runs the Playwright tests against it; `npm run bench` (root) runs the benchmark scenarios on its production build.
